Votre compte Le p'tit Canif

Quand vous créez un compte dans une application Le p'tit Canif, ce compte est valable pour toutes les autres.

Un compte commun

Les applications Le p'tit Canif sont indépendantes, mais elles reconnaissent le même compte. Vous vous inscrivez une fois, puis vous vous connectez partout avec les mêmes identifiants.

Ce qui est partagé, ce qui reste séparé

Partagé entre les apps

  • Votre adresse e-mail
  • Votre mot de passe

Séparé dans chaque app

  • Les données de chaque app (par exemple vos plantes dans une app de jardin)
  • Elles sont rangées à part et vous seul(e) y avez accès

Changer de mot de passe

Dans n'importe quelle app, sur l'écran de connexion, utilisez le lien « Mot de passe oublié ». Vous recevez un e-mail pour en choisir un nouveau. Le changement vaut pour toutes les apps Le p'tit Canif.

Supprimer vos données

Chaque app a un bouton de suppression de vos données dans ses Réglages. Il efface les données de cette app, sans toucher à celles des autres.

À COMPLÉTER Préciser si ce bouton supprime aussi le compte lui-même (e-mail et mot de passe), et sinon comment demander cette suppression.

Questions fréquentes

J'ai déjà un compte Jeu-Sais, dois-je en créer un autre pour une autre app ?

Non. Connectez-vous simplement avec le même e-mail et le même mot de passe.

Si je supprime mes données dans une app, les autres sont-elles touchées ?

Non. Les données de chaque app sont séparées.

Une app peut-elle voir les données d'une autre app ?

Non. Chaque app range ses données dans un espace séparé, réservé à son propriétaire. Pour le détail technique, voir la page de confidentialité.

Qui peut me répondre en cas de problème ?

Écrivez à l'éditeur : voir les coordonnées sur la page de confidentialité.
